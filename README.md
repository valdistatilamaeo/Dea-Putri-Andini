# Dea Putri Andini - Professional Web Portfolio

![Dea Putri Andini Portfolio Banner](avatar.png)

Website portofolio interaktif dan modern untuk **Dea Putri Andini**, seorang spesialis **Pengendalian Mutu Operasional, Digitalisasi Kearsipan Keuangan, dan Inventory Control**.

## 🌟 Fitur Utama Website
- **Modern Responsive Design**: Responsif penuh untuk perangkat seluler, tablet, dan desktop dengan efek *Glassmorphic UI* & *Dynamic Particle Canvas*.
- **Dark / Light Theme Switcher**: Pengubah tema gelap dan terang secara instan.
- **Bilingual Support (ID / EN)**: Fitur alih bahasa Indonesia dan Inggris.
- **Filterable Projects & Modals**: Filter kategori proyek beserta modal pop-up interaktif untuk detail hasil kerja (Metode ERM, Rekapitulasi Excel, LPJ Keuangan, Stock Opname).
- **Stat Counter & Interactive Form**: Animasi statistik rekam jejak kerja & formulir kontak interaktif.
